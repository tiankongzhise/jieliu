# jieliu
Smart Utility Tracker
go服务，主要是记录燃气和电费每日差额，估算每日用电和用气量，记录并统计。实现前端展示。 从百度云盘指定文件夹扫描文件，与数据库记录的已读文件比对，增量读取文件。然后根据文件名称和图片内容识别日期。图片内容没有日期的，以图片名称日期为准，图片内容有日期的以图片日期为准。 读取数据，填写如数据库。然后根据长沙市电气的计费规则，根据两日的余额查和所处档位估算昨日用电或燃气量。记录在数据库， 可以在web端由人工修正数据。

开发现状
该服务基本满足需求描述，但现阶段无法直接投入生产使用，主要问题在于：

必须接入真实OCR引擎（否则无法自动提取图片中的日期和余额）。

必须修正燃气阶梯算法，增加年度累计用气量参数，并实现正确的档位判断。

若将上述两点修复，并适当处理时间间隔问题（如插值或提示），则该服务可完全满足需求。

🔧 改进建议
集成OCR
替换mockOCR，调用paddleocr或tesseract，提取日期和余额数字，并完善正则匹配逻辑。

燃气累计计算

在calcAllDailyConsume中维护一个年度累计变量（按年份），每次计算时传入已用气量，并在计算后累加。

修改calcGasUsage签名，增加yearlyUsed参数。

时间间隔处理

若相邻记录日期差>1天，可选择平均分配用量到每一天，或只记录当日并提示用户，视业务场景而定。

异常处理

扫描时若文件无法识别，除标记异常外，可在Web端增加“手动补录账单”入口，方便人工录入。

安全增强

建议使用bcrypt存储密码，而非明文比较。

要预留接口，为以后添加用水分析做准备

时间的规则需要抽象出来一层，允许水电气有各自不同的多个提取时间的规则。允许对re规则设置权重，权重高的优先生效。对名称和对内容提取时间可以使用不同的提取规则。

水电气的阶梯计价，计费周期。不同阶梯的限额和费用，需要可以配置。带默认配置。也可以用户在web界面修改，也允许用户上传配置文件修改。

将当个main.go文件按照go服务的项目管理拆分出不同模块，各司其职。

百度网盘要允许用户web扫码授权，网盘token要加密加盐保存。可以通过算法恢复使用。

允许用户注册并且绑定和解绑百度网盘。

用户可以指定临时授权登录和永久授权百度网盘。临时授权分为一天，一周，一个月。到期后会自动删除保存的百度网盘token.
